# LLM Lecture Companion App

This project aims to build an Android application that records lectures in the background, transcribes them, extracts text from accompanying PDF course materials (including scanned pages), and produces concise summaries using GPT-5 Mini.

See [`docs/android_app_plan.md`](docs/android_app_plan.md) for the detailed product and technical plan covering architecture, data models, and milestones.
